# ImageLab

本地生图工作台。写提示词 → 点生成 → 出图，不用碰 ComfyUI 的节点图。

当前引擎：**Qwen-Image 2.1**（架构上按"引擎"分层，以后可以并挂别的生图模型）。

双击 `启动_ImageLab.bat`。

---

## 环境依赖与安装

| 依赖 | 要求 |
|---|---|
| ComfyUI | **≥ v0.42.1**（便携版或源码版都行）。ImageLab 用到的节点（`QwenImage21Cache`、`TextEncodeQwenImage21`、`TextGenerate`、`PreviewAny` 等）全是 ComfyUI 内置的 comfy_extras，**不需要装任何第三方 custom_nodes** |
| 显卡 | NVIDIA，建议 16 GB 显存（图像编辑模式峰值约 15.4 GB） |
| 浏览器 | Edge 或 Chrome（当应用窗口用；Python 侧没有任何第三方依赖） |
| Python | 无需额外安装——直接复用 ComfyUI 便携版自带的 `python_embeded` |

**ImageLab 怎么找到 ComfyUI**（按优先级）：

1. 命令行参数 `--comfy-home <ComfyUI 目录>`
2. 环境变量 `IMAGELAB_COMFY_HOME`
3. 自动探测：与 ImageLab 目录同级（相邻）的 `ComfyUI_windows_portable` 或 `ComfyUI`

把 ImageLab 放到你的 ComfyUI 旁边，双击 `启动_ImageLab.bat` 就能跑。

**权重不进仓库，需自行下载**（ModelScope / HuggingFace 搜 Qwen-Image 2.1 的量化权重，直连不通走 hf-mirror.com）。放置目录都在 `ComfyUI\models\` 下，文件名必须与下表一致——ImageLab 按文件大小判断"已安装"，名字不对会被视为未装：

| 文件 | 目录 | 大小 |
|---|---|---|
| `qwen_image_2.1_int8_convrot.safetensors` | `diffusion_models\` | 6.8 GiB |
| `qwen_image_2.1_turbo_int8_convrot.safetensors`（可选，Turbo 引擎） | `diffusion_models\` | 6.8 GiB |
| `qwen3vl_8b_w4a8.safetensors`（默认文本编码器） | `text_encoders\` | 5.9 GiB |
| `qwen3vl_8b_int8_convrot.safetensors`（可选，理论画质更好） | `text_encoders\` | 8.7 GiB |
| `qwen_image_2.1_vae_bf16.safetensors` | `vae\` | 0.63 GiB |
| `qwen3.5_9b_qwen_image_2.1_pe_t2i_w4a8.safetensors`（可选，提示词增强） | `text_encoders\` | 6.3 GiB |
| `qwen3.5_9b_qwen_image_2.1_pe_i2i_w4a8.safetensors`（可选，提示词增强） | `text_encoders\` | 6.3 GiB |

> 模型权重自带各自的模型许可，与本仓库代码的许可（MIT，见 `LICENSE`）相互独立。

## 一、三种用法

### 文生图

写提示词，点生成。默认 1024×1024 / 20 步，约 10 秒一张。

### 图像编辑（图生图）

切到「图像编辑」，加参考图，写"改什么"：

```
把台阶上的猫换成一只白色小猫
```

参考图有两种来源：

- **+ 按钮**：从本机选图片（支持多选、拖入 10 张以内）
- **「用作参考图」按钮**：把当前预览的图直接变成参考图（自动切到编辑模式）

**输出尺寸跟随参考图比例**，由「编辑精度」决定总像素：

| 编辑精度 | 输出（以 3:4 参考图为例） | 显存峰值 |
|---|---|---|
| 512 | 448 × 576 | 约 14 GB |
| 1024（默认） | 896 × 1152 | 15.4 GB |
| 1280 / 1536 | 更大 | 容易 OOM，16 GB 不建议 |

⚠️ 编辑模式显存峰值 **15.4 GB**，比文生图（14.3）更吃紧。跑之前务必关掉游戏和壁纸引擎，别同时开浏览器看视频。

## 实测：编辑到底做了什么

用同一张照片（工地废木料场景）做「画面变成水彩风格」：

- 参考图 896×1152 竖版 → 输出 896×1152，**构图、机位、每根木头的走向全部保留**，只换了画风
- 耗时：12 步约 20 秒（首次含加载会更久），显存峰值 15.4 GB
- 3 张参考图：35.6 秒，峰值仍是 15.4 GB

这是真正的图像编辑，不是重新画一张。

### 批量

「批量」选预设张数，或选「自定义」填任意值（1–32）。同提示词、不同种子连续出图。勾了「随机种子」就是随机；填了固定种子则按 `种子 / 种子+1 / 种子+2` 递增。

耗时按张数**线性叠加**——两批任务不同时跑，显存占用跟单张一样。这就是为什么批量上限可以放宽到 32：瓶颈只在时间，不在显存。

| 批量 | 标准版 1024/20步 | Turbo 1024/8步 |
|---|---|---|
| 4 张 | 约 35 s | 约 13 s |
| 12 张 | 约 1.7 分 | 约 44 s |
| 32 张 | 约 4.6 分 | 约 2 分 |

### 中途停止

生成过程中，按钮会变成红色的「■ 停止生成」，也可以直接按 **Esc**。

停止走的是 ComfyUI 的 `/interrupt` + 清空排队队列：正在采样的那一张立刻中断，不会等这一步跑完。因为批量是逐张提交的，队列里通常只有一个任务，所以收尾通常在 1 秒内（实测日志：15:48:12 点停止，15:48:13 任务结束）。

已经出好的图**不会丢**：

- 停在第 1 张之后 → 结果条里保留那 1 张，计数显示 `1 / 4（已停止）`
- 一张都没出就停 → 显示「已停止」，不留空记录
- 已出的图照常写进历史记录，提示词、种子、参数都在

停止只影响本次生成，模型仍留在显存里，再点生成立刻就能跑。

### 图库

右下角「图库 ▸」打开已生成图片的管理面板（对应磁盘目录 `ComfyUI\output\`）：

| 功能 | 说明 |
|---|---|
| 浏览 | 按修改时间倒序，缩略图网格，每次加载 60 张，可「加载更多」 |
| 预览 | 点缩略图 → 大图显示到主界面，可直接保存/用作参考图 |
| 筛选 | 顶部输入框按文件名过滤，如 `ImageLab`、`cmp` |
| 单删 | 悬停缩略图右上角 ✕，二次确认后删除 |
| 批量删 | 勾选左上角复选框，可「全选」，再点「删除选中」 |
| 打开文件夹 | 在资源管理器中定位（已选中当前预览的图） |

删除是**真删磁盘文件**，不可撤销，所以都有二次确认。删除后主界面若正在显示该图会自动清空。

界面统计会显示「当前列表 N 张 · XX MB」，方便清理占空间的老图。

## 二、界面说明

顶部状态栏三个胶囊：**后端状态**、**显存占用**、**模型**。

「模型」显示的是完整引擎名 + 权重精度（当前 `Qwen-Image 2.1 · INT8`），鼠标悬停可看到具体权重文件、文本编码器和 VAE 的文件名。这个名字**由后端 `/api/health` 返回**，前端不拼缩写——以后接新模型时不用改前端。

| 控件 | 说明 |
|---|---|
| 文本编码器 | **W4A8**（省显存，默认）/ **INT8**（理论画质更好）。切换后第一张要重新加载模型，多等几秒 |
| 尺寸 | 1024² / 896×1152 / 1152×896 / 768²。编辑模式下自动禁用——尺寸由参考图决定 |
| 步数 | 4–30，默认随引擎（标准版 20，Turbo 8）。越多越细，耗时线性增长 |
| 模型引擎 | 下拉切换。未安装的引擎会灰掉并标注「未安装」；切换后自动套用该引擎的默认步数 |
| 批量 | 1 / 2 / 4 / 8 / 16，或选「自定义」填 1–32 的任意值。选了 2 张以上时，标签右侧会显示预估耗时（基于同引擎+同尺寸+同步数的上次实测） |
| 随机种子 | 勾选则每次不同；取消后可复现 |
| 显存 | 已用/总量。超过 15.5 GB 时变黄 |

底部两个标签页：

- **本次结果**：这一批出的所有图，点缩略图切换预览。批量出图途中点选后，后续到达的新图不会把预览抢回第一张（只有新一轮任务才恢复自动跟随）
- **历史记录**：最近 100 条，**存在服务端 `history.json` 里**（不是浏览器缓存），点一条可以恢复当时的提示词、参数、种子和参考图。悬停条目右侧的 ✕ 删除单条，右上角「清空」清空全部——**只删记录，不删图片文件**

> 为什么不用 localStorage：浏览器的存储按 origin（含端口）隔离。8765 被占用时程序会自动换端口，换了端口历史就"消失"了。改存服务端后，换端口、换浏览器、清缓存都不丢。

## 三、提示词增强（PE）

提示词框右上角有个「✦ 增强」按钮：用 Qwen3.5-VL 9B 微调的 **PE 模型**把一句话扩写成详细的中文画面描述。

```
输入：雨夜老街上一家小书店，招牌写着「夜雨书店」
输出：雨夜的老街巷中，一家临街的小书店成为视觉焦点。画面整体为横向构图，
      采用略微仰视的街道视角，暖黄色的店铺灯光与冷蓝色的雨水夜色形成强烈对比……
```

| 项目 | 说明 |
|---|---|
| 文生图 | 用 PE-T2I，约 5 秒 |
| 图像编辑 | 用 PE-I2I，会读参考图，约 10 秒 |
| 模型体积 | 各 6.4 GB（W4A8），已下载到 `text_encoders\` |
| 显存峰值 | 加载时约 9.7 GB，与画图模型互斥，出图时自动换回 |

增强结果会**替换输入框内容，可以继续手动改**。点「↩ 还原」可撤销。

### 两道防护

PE 是自由生成的，偶尔会跑偏。所以后端加了两道检查，**不合格就丢弃、绝不覆盖你的原文**：

1. **退化检测**：结果重复词堆砌或过短 → 报错「增强结果异常」
2. **文字保真检测**：原文 `「」` 里的字如果在结果里消失了（被翻译/改写）→ 报错并指出是哪一段

看到这两种提示，再点一次「✦ 增强」就行。

### 增强被安全策略拒绝

如果提示「增强被模型的安全策略拒绝」，那是 **PE 模型自带的内容审查**（不是 ImageLab，也不是画图模型），常见于描述里出现可能被判为未成年的角色，或身体/亲密相关的措辞。

处理方式：

- **直接跳过增强**——PE 只是把提示词写详细，直接点生成完全不影响出图
- **写明确**：角色加上"成年 / 30 岁 / 职业"这类限定，避免"少女 / 萝莉 / 学生 / 幼"等词
- **玩偶、手办、毛绒玩具类**：明确写成"毛绒玩偶 / 商品静物摄影"，不要出现人体部位的描写

原文会保持不动，不会被拒绝信息覆盖。

> 注意：这个审查在模型侧，改 `PE_SYSTEM_PROMPT` 是绕不过去的，也不应该尝试。涉及未成年的性化内容属于硬性红线。

### 使用时注意

- **要渲染中文文字时，务必用 `「」` 括起来**——防护靠它来检查，不括的话被改掉也不会拦
- 短提示词收益最大；已经写得很细的提示词，增强可能反而画蛇添足
- 想复现某次增强结果：同一输入会命中缓存（0.5 秒返回）

## 四、两个已知行为

**1. 相同提示词 + 相同种子 = 瞬间返回**

ComfyUI 会缓存结果，1 秒内返回的其实是缓存图。想对比参数就换种子。

**2. 中文文字要用中文提示词**

整个提示词用中文写，要渲染的字用 `「」` 括起来：

```
一块木制招牌，上面用粗黑体写着「夜雨书店」四个汉字，白天，字迹清晰可辨
```

英文描述里嵌中文会退化成一串问号。

## 五、出问题时

| 现象 | 原因 | 处理 |
|---|---|---|
| 页面顶部出现红条「连接已断开」 | 后台进程退出了 | 关掉窗口，重新双击 `启动_ImageLab.bat` |
| 点生成报「连不上本地服务」 | 同上 | 同上 |
| 参考图缩略图裂开 | 已修复（2026-10-20） | 更新后不再出现 |
| 状态一直停在「启动中…」 | 显存不够，ComfyUI 起不来 | 关游戏/壁纸/模拟器 |
| 用了一阵子突然「连接已断开」 | 旧版看门狗误杀（2026-10-22 已修） | 重开一次；新版不会再自己退出 |
| 出图报显存不足 | 峰值超了 | 降尺寸、批量减到 1 |

**日志**：`imagelab.log` 记 app 自己的动作（启动、退出原因），`comfyui.log` 记出图过程。出问题先看这两个。

**退出行为**：关窗口后约 15 秒释放显存（要确认前端确实停止响应才退，避免误杀）。想立刻释放就点右上角「退出」。

## 六、实现方式

```
app.py ──启动──> ComfyUI (127.0.0.1:8188)
   │
   └─ 本地 HTTP 服务 (127.0.0.1:8765) ──> Edge --app 窗口（无地址栏/标签页）
```

- 没装 tkinter（便携版 Python 里被裁掉了），所以用 `Edge --app` 做窗口，**零新增依赖**
- 后端自动检测：ComfyUI 已在跑就直接复用，不会起第二份抢显存
- 退出时只关自己启动的实例，不影响你手动开的 ComfyUI
- 窗口存活只认 `EnumWindows` 枚举到的窗口标题；心跳仅用于「窗口已消失」时的二次确认，**没有任何基于心跳的独立超时**。历史教训：早期版本有个"5 分钟无心跳就退出"的兜底，结果窗口最小化/锁屏时 Chromium 冻结定时器，程序把自己杀了，界面显示"连接已断开"
- 心跳是前端每 8 秒的 `POST /api/beat`，后端 `touch_heartbeat()` 记录时间；`GET` 也认。**两种方法都必须处理**——只注册了 GET 的话 POST 会 404，`LAST_BEAT` 永远停在启动时刻，二次确认就形同虚设（2026-10-22 修，实测修复前浏览器在发心跳的情况下程序仍在 15 秒后退出）

### 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/health` | 后端状态、模型、可用编码器、显存 |
| POST | `/api/generate` | 提交任务（含 mode / refs / batch / clip） |
| GET | `/api/progress?id=` | 进度与结果（含 `cancelled` 标记） |
| POST | `/api/cancel` | 停止任务（`{"id": "..."}`），中断执行 + 清队列 |
| GET | `/api/view?filename=` | 取图 |
| POST | `/api/upload` | 上传参考图（原始字节 + `X-Filename` 头） |
| POST | `/api/ref-from-output` | 把已生成的图复制成参考图 |
| POST | `/api/enhance` | PE 提示词增强，返回扩写后的文本 |
| POST | `/api/engine` | 切换引擎（`{"id": "..."}`），返回新引擎与列表 |
| GET | `/api/library?limit=&offset=&q=` | 图库列表（按时间倒序，支持筛选） |
| POST | `/api/library/delete` | 删除图片（`{"names": [...]}`，仅限 output 目录内） |
| POST | `/api/open-folder` | 在资源管理器中打开输出目录 |
| GET | `/api/history` | 读全部历史记录 |
| POST | `/api/history/add` | 追加一条（出图完成时后端自动调用） |
| POST | `/api/history/import` | 导入旧 localStorage 历史（仅首次为空时） |
| POST | `/api/history/delete` | 删除指定历史（`{"ids": [...]}`） |
| POST | `/api/history/clear` | 清空历史 |
| POST | `/api/quit` | 退出并释放显存 |
| GET/POST | `/api/beat` | 前端心跳（每 8 秒），仅供看门狗二次确认 |

### 引擎与多模型

引擎在 `app.py` 顶部的 `ENGINE_DEFS` 里注册，现在有两个：

| 引擎 | 权重 | 默认步数 | 实测（1024，热态） |
|---|---|---|---|
| Qwen-Image 2.1 | `qwen_image_2.1_int8_convrot` | 20 | **8.7 s** |
| Qwen-Image 2.1 Turbo | `qwen_image_2.1_turbo_int8_convrot` | 8 | **3.3 s** |

Turbo 是同一模型的蒸馏版，画质略降但快 2.6 倍，适合快速试构图。

每个引擎的定义长这样：

```python
"qwen-image-2.1": {
    "name": "Qwen-Image 2.1",
    "vendor": "Alibaba Qwen",
    "builder": "qwen_image_21",        # 用哪个构图函数
    "unet": ["qwen_image_2.1_int8_convrot.safetensors"],
    "min_bytes": 6_500_000_000,        # 小于这个视为没下完
    "defaults": {"width": 1024, "height": 1024, "steps": 20},
    "caps": {"refs": True, "encoder": True, "pe": True},
    "note": "标准版，20–25 步，质量优先",
}
```

**接一个新模型**：

1. 在 `ENGINE_DEFS` 加一项
2. 架构不同（比如 Flux）就写一个 `build_flux(...)` 并注册进 `BUILDERS`
3. 权重放进 `models\diffusion_models\`，`min_bytes` 设对
4. 前端不用改——下拉框会自己出现

「已安装」判断会检查**文件大小**而不只是存在，否则下到一半的权重会被当成可用，加载时才炸。

能力位 `caps` 是给前端留的扩展点（某引擎不支持参考图就藏掉编辑模式）；目前两个引擎能力相同，前端还没按 `caps` 做差异化显示。切换引擎时后端会记住选择，`/api/generate` 也可以显式带 `engine` 字段覆盖。
